# Artilect Production

Read `AGENTS.md` and follow it as the production contract. The user supplies the creative subject and desired technologies X/Y/Z. Your output is **real content and a reproducible producer-owned repository**, not just a list of links. Keep upstream technologies as direct Git submodules in `technologies/`. Put production instructions in `production/`, credits and watch links in `README.md`, and media metadata in `artilect.json`. Run `python scripts/validate.py` before offering to submit. Obtain the human's approval before public publishing.
